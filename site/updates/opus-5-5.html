    01 / WHAT CHANGED

    The numbers, side by side.

    A coding agent gets an embodied video and writes the scene, physics and robot behavior needed to recreate the interaction. Video2World executes that code and checks whether the task actually happens. In the supplied snapshot, Opus 5.5 reaches 52.41 V2WScore and 29.4% task success, ahead of Fable 5.1 (44.13, 20.2%) and Opus 5 (37.91, 11.5%).

    02 / CLIMBING THE LADDER

    Seeing is level. Doing pulls ahead.

    Claude Opus 5.5 vs Claude Fable 5.1
    Rung 1

    Seeing

    Does the world reproduce what was observed? On scene, object shape and size, Opus 5.5 and Fable 5.1 are effectively level; the terminal rotation error is somewhat lower for Opus 5.5.

    Rung 2

    Doing

    Does the robot's own action make the outcome happen? This is where the two models separate: task success and stage progress both move clearly in Opus 5.5's favor.

    Rung 3

    Imagining

    Does the world still behave correctly when something changes after it is built? This intervention test has not yet been run on Opus 5.5. It is the next measurement.

    03 / WHAT STILL NEEDS WORK

    A new high.
    Still a hard problem.

    Task success remains below 30% in this snapshot: most worlds that Opus 5.5 builds still do not get the task done.

    Opus 5.5 does not lead every diagnostic. Its Fixed-ref Task is 8.6%, compared with 11.4% for Fable 5.1, and its terminal relative translation error (26.65 cm) is close to Fable 5.1's (27.20 cm).

    For a sense of headroom: in the published paper results, a separate result set, the human-assisted reference, which also has extra source information and manual refinement, succeeds on about six in ten tasks. That figure is a qualitative reference only; it is not directly comparable with this snapshot.
